# Cash App Data Breach — GRC Audit and Gap Analysis

## Overview
This project is a governance, risk, and compliance (GRC) audit of the 2021 Cash App 
insider threat data breach, conducted as part of my Legal Aspects of Cybersecurity 
coursework at Stevenson University. The analysis applies a structured audit methodology 
to a real-world breach, identifying control failures, regulatory violations, and 
actionable remediation steps.

## Objectives
- Apply NIST SP 800-53 control assessments to evaluate Block Inc.'s security posture
- Identify specific control failures that enabled the breach
- Map violations across multiple regulatory frameworks
- Develop a remediation roadmap, translating compliance gaps into technical controls
- Design a formal Cybersecurity Law Program (CLP) for organizational implementation

## Methodology
- Reviewed publicly available breach disclosures, SEC filings, and investigative reports
- Applied 20 NIST SP 800-53 controls to the breach timeline and attack vector
- Mapped findings to GDPR, CFAA, and SEC disclosure requirements
- Used structured gap analysis techniques to prioritize remediation by risk severity

## Key Findings
- Identified 10 critical NIST SP 800-53 control failures, including:
  - AC-2 (Account Management) — terminated employee retained access post-departure
  - IR-6 (Incident Reporting) — SEC disclosure timeline violated
  - PS-4 (Personnel Termination) — inadequate offboarding controls
- Documented violations across SEC, GDPR, and CFAA regulatory frameworks
- Determined breach was preventable through standard access control hygiene

## Deliverables
- Structured gap analysis report with control-by-control assessment
- 4-point remediation plan mapping compliance gaps to technical controls
- Cybersecurity Law Program design, including Business, Functional, and Technical views
- RACI matrix defining accountability across security, legal, and IT stakeholders
- NIST SP 800-53 control-to-regulation mapping (SOX, HIPAA, GDPR, CFAA)

## Frameworks and Tools Used
- NIST SP 800-53 Rev 5
- NIST Privacy Framework
- GDPR Articles 32 and 33
- SEC Regulation S-K Item 106
- Computer Fraud and Abuse Act (CFAA)
- Sarbanes-Oxley Act (SOX)
